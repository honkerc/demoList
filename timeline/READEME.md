# TimeLine · 时间线

> 像柳比歇夫一样记录时间，像工匠一样雕琢人生。

---

## 📖 项目概述

**TimeLine** 是一款受 **柳比歇夫时间管理法** 启发的时间记录与分析应用，覆盖 **Android / iOS / Web** 三端。

> 柳比歇夫（1890–1972）用一生践行了「时间统计法」—— 不是机械地打卡，而是通过**精确记录 → 客观分析 → 持续优化**，让时间成为可量化的生命材料。

本项目的核心理念：

| 理念 | 说明 |
|------|------|
| 🎯 **专注聚焦** | 不是事无巨细地记录每一秒，而是记录**对你真正重要的事** |
| 📊 **数据驱动** | 用可视化图表让你看清时间流向，而非凭感觉 |
| 🔄 **持续迭代** | 每日/周/月复盘，让时间分配越来越接近你的优先级 |
| 🧘 **极简交互** | 记录操作不超过 3 秒，不打断心流状态 |
| 🔗 **开放生态** | 与 GitHub 深度集成，数据可导出、可版本管理、可自动化 |

## 🎨 设计风格

### 视觉语言

```
风格：简约 · 大气 · 克制
配色：以黑白灰为基底，用低饱和色彩区分时间类别
字体：无衬线字体（SF Pro / Inter），层级清晰
留白：大量留白，让每个元素都有呼吸感
动效：微交互动效，克制且有意义（非装饰性）
```

### 色彩体系

| 用途 | 色值 |
|------|------|
| 背景渐变 | `radial-gradient(ellipse at 30% 10%, #fff5f0, #fef3e8)` |
| 深色背景 | `radial-gradient(ellipse at 30% 10%, #1a1a1a, #000000)` |
| 卡片 | `#FFFFFF` / `#1C1C1E` |
| 主文字 | `#1D1D1F` / `#F5F5F7` |
| 次要文字 | `#6E6E73` / `#A1A1A6` |
| 辅助文字 | `#86868B` / `#6E6E73` |
| 分割线 | `#D2D2D7` / `#38383A` |
| 强调色 | `#0071E3`（蓝） |
| 类别色 | 8 种低饱和色系，每个类别固定色值 |

### 设计原则

1. **内容优先** — 装饰不喧宾夺主，信息层级一目了然
2. **单手操作** — 核心操作在屏幕下半区，拇指可达
3. **渐进呈现** — 先展示概览，需要时再展开细节
4. **一致性** — 跨平台统一的设计语言
5. **深色模式** — 在「我的」页面设置中切换，全局生效

## 🧩 核心功能

### 1. 时间记录（Time Logging）

- **一键记录** — 选择时长 + 活动名称 + 类别，点击即记录
- **预设时长** — 15m / 25m / 30m / 45m / 60m / 90m / 120m 快速选择
- **8 大类别** — 工作 / 学习 / 阅读 / 运动 / 创作 / 社交 / 休息 / 其他
- **今日时间轴** — 实时展示当天每小时的时间分配
- **空白时段显示** — 可切换显示/隐藏空白时段

### 2. 任务管理（Task Management）

- **添加任务** — 输入任务名称，一键添加
- **完成切换** — 点击任务切换完成状态，带 ✓ 动画
- **删除任务** — 悬停显示删除按钮
- **自动排序** — 未完成在前，已完成在后
- **本地持久化** — 使用 localStorage 存储

### 3. 时间线回顾（Timeline Review）

- **日期导航** — 左右切换查看任意一天
- **每日统计** — 总记录时长、活动数、利用率
- **时间线列表** — 按时间顺序展示活动，含类别色条
- **间隙显示** — 自动计算活动之间的时间间隔
- **删除记录** — 点击可删除单条记录

### 4. 数据看板（Dashboard）

- **周期切换** — 本周 / 本月 / 全部
- **概览卡片** — 总记录、日均、活动数、完成率
- **每日趋势图** — 柱状图展示每日时间投入
- **分类分布图** — 环形图展示各类别占比
- **目标进度** — 每日专注 / 每周阅读 / 每周运动
- **智能洞察** — 自动生成时间分析建议

### 5. GitHub 集成（GitHub Integration）

- **数据版本管理** — 时间数据以 YAML/JSON 格式存入 GitHub 仓库
- **自动提交** — 每日自动 commit 当日数据
- **GitHub Actions** — 自动生成周报/月报并推送
- **多设备同步** — 通过 GitHub 仓库实现多端数据同步
- **公开/私有** — 可选择公开时间数据或私有仓库

## 🎯 设计决策记录

### 为什么用 5 个 Tab？

柳比歇夫时间管理法的核心是：**记录 → 分析 → 优化**。5 个 Tab 对应：

| Tab | 对应环节 | 说明 |
|-----|---------|------|
| 记录 | 记录 | 快速录入时间数据 |
| 任务 | 规划 | 管理待办事项，与时间记录联动 |
| 时间线 | 回顾 | 查看每天的时间分配明细 |
| 看板 | 分析 | 可视化数据，发现模式 |
| 我的 | 配置 | 个人设置、数据管理、GitHub 同步 |

### 为什么深色模式放在「我的」页面？

- 保持记录页面的极简，减少干扰
- 深色模式是「设置」而非「日常操作」
- 用户通常在「我的」页面进行一次性配置
- 所有页面自动继承主题设置

### 为什么任务页没有筛选/统计？

- 聚焦核心功能：添加 + 完成 + 删除
- 未完成自动置顶，无需手动筛选
- 统计信息在看板页统一展示
- 保持页面轻量，加载即用
